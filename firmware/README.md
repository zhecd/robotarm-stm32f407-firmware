# 正式固件190

`ProductionRelease.hex`与`ProductionRelease.bin`是完整正常入口，MCU为STM32F407VETx、Flash基地址0x08000000；HEX自带地址，BIN下载需显式设此地址。功能未编译锁定。

**上电/复位会自动关闭夹爪并三轴并行回零。** 寻退1000微步/秒、退100°/31°/10°、整轮220秒截止，115200不变。保证行程、支撑和线束允许；下载与复位由操作者自行执行。本仓库构建/CI不自动烧录或动作。

本目录固件来自已校验190，见SHA256SUMS。发布树会独立构建并比较HEX/BIN，而不是仅复制文件后宣称构建通过。需要输出锁定诊断版时从源码使用ProductionLocked预设，避免误当正式运行版。

实际运行体验、绝对精度、扰动补偿和降噪验证边界见 [验证说明](../docs/validation.md)。
