# 硬件与引脚

本固件功能基线使用STM32F407VETx及PCB10_1实机。下表来源于当前Core和BSP；其他PCB版本须逐项核对，不能仅凭接口外形插接。仓库未包含原理图/PCB制造文件。

| 功能 | 引脚/接口 |
|---|---|
| 上位机USART1 | PA9=TX，PA10=RX，115200/8N1，3.3V TTL；USB串口TX接PA10，RX接PA9，共地 |
| TMC2209 USART6 | PC6=TX、PC7=RX；单线总线接法见实际控制板，软件节点地址0/1/2 |
| 共用EN | PD2，低有效；三路同时上电，只有被选轴收到STEP |
| M1/M2/M3 STEP | PA6、PA7、PB0 |
| M1/M2/M3 DIR | PD3、PD4、PD5 |
| M1/M2/M3限位 | PC10、PC11、PC12，普通上拉GPIO，低有效；PCB10_1 CN3/CN4/CN5 |
| 电机接口 | M1 CN15、M2 CN16、M3 CN17 |
| MODE | 控制板SW7/KEY1/PE2，EXTI2；不是PS2手柄MODE键 |
| LED1/2/3/4 | PC0/PC1/PC2/PC3；代码LED_0对应板上LED1 |
| PS2 DAT/CMD/CS/CLK | PE12/PE13/PE14/PE15 |
| MG90S | H2：PA1/TIM2_CH2 PWM、板上5V、GND；原开100°、关72° |
| 编码器 | M1 I2C1、M2 I2C2、M3 I2C3，AS5600 |

控制板主电源为12V，板上转换产生5V/3.3V。TMC VM必须经实际电源开关供电；MCU串口应答不证明电机驱动已供电。沿用外部主供电时不要并接ST-Link的3.3V供电输出；电压参考输入与供电输出须按工具标识区分。

LED1在G-code模式常亮，PS2模式亮500ms/灭500ms。LED2/3/4对应三路限位原始输入，压下亮、松开灭；稳定消抖后的业务判定可能滞后10ms。手柄接管需回中松键，只允许空闲时切换模式。

断电/禁用会失去保持力，尤其M3可能受重力移动。正式固件上电自动动作；先确认机构支撑、有效行程和线束。硬件接线以当前源码及自己的实物为准，不套用历史测试记录的现场状态。
