# 验证范围与已知限制

## 2026-11-20 发布验证

- 本机 Debug 和 Release 各通过 559 项测试，包含运动队列清空后仍需等待闭环反馈、补偿未结束和故障中止的串口回归。
- 用 Arm GNU Toolchain 15.2.Rel1 构建通用 Release、通用 Debug 和视觉工位 Release，并审核生成的 ELF。源码重建的工位 HEX 与此前烧录文件一致，HEX 的 95,276 字节有效数据与历史 Flash 读回一致。
- 视觉工位此前回零后报告 `READY`、`HOMED:1`、`FAULT:0`，`M114 PLAN` 为 X0、Y192、Z245 mm。这里的 XYZ 是固件模型坐标。
- 配套上位机此前走正式入口完成一轮红、黄、蓝分拣，三个物体均进入对应格。该轮采用固件 R=52 mm、上位机等效 R=50 mm，结束后回到拍照位，控制器状态为 `READY`。回拍校验仍曾报出桌面特征偏移。 [上位机实机记录](https://github.com/zhecd/robotarm-color-sorting-host/blob/01bcfd27030702800714016f935a7663981a98fd/docs/validation/result.json)

本次发布沿用上述实机记录和读回镜像。 [机器可读摘要](validation-summary.json)

## 历史实机证据

2026-11-14 的旧版有回零、串口查询和空闲模式切换记录。更早的整机检查覆盖空载 XYZ 六段 5 mm 移动、串口与 PS2 夹爪开合、模式切换和 60 秒保持。各记录适用于当时使用的固件与现场条件。

## 仍需独立验证的项目

- 实际末端绝对定位精度、长期分拣成功率和相机安装重复性。
- 实际 10° 扰动恢复、持续运行稳定性，以及驱动噪声和扭矩表现。
- 新版手柄拨杆与夹爪运动专项、偶发 PS2 异常帧根因。
