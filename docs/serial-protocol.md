# 串口协议 PROTOCOL:1

USART1 PA9(TX)/PA10(RX)，115200/8N1、3.3V TTL。每行一条ASCII命令，推荐CRLF，兼容CR/LF；最多255字符（不含结束符）。半行500ms无续传作废，超长/溢出/接收错误不会继续拼接残留内容。`#`开头为日志。

| 指令 | 含义与主要回复 |
|---|---|
| `M115` | 固件身份、协议、UART、FEATURES |
| `M408` | STATE/HOMED/ALLOWED/MODE/FAULT/MOTION_FAULT/QUEUE/PENDING/RECOVERY/IRQ_LATCH_MASK |
| `M114` | PLAN XYZ、J关节角、ENC电机角；参考无效时报错 |
| `M119` | M1/M2/M3 `OPEN`或`TRIGGERED` |
| `M409` | 反馈代数、逐轴年龄、FRAME、PRESENT/VALID/FRESH掩码、MOTOR/JOINT |
| `M410` | 夹爪目标、PWM请求、600ms保持与ERROR；POSITION始终UNMEASURED |
| `M411` | 闭环REF/CONTROL/ACTIVE、目标及误差电机角、补偿轮数与最近微步数 |
| `M412` | PS2有效/无效计数、最后帧、首坏帧；查询不读取总线或清除记录 |
| `M126` | 回零阶段、原因、接触/完成位图、SEEK/BACK、PARALLEL/STEP_MASK/DIR_MASK |
| `M127` | 回零稳定确认、输入观察及SEEK/BACK周期参数 |
| `G1 X… Y… Z… F…` | 机械臂模型中的绝对位置；XYZ毫米，F正整数毫米/分钟，最大3000 |
| `G0 X… Y… Z… F…` | 当前使用与G1相同的分段直线执行方式 |
| `M400` | 路径和步进队列完成后，等待闭环稳定及三轴新鲜反馈进入到位死区，成功返回 `ok` |
| `M3` | 夹爪打开100°；成功`M3OK` |
| `M5` | 夹爪关闭72°；成功`M5OK` |
| `M112` | 软件停止、禁用输出、撤销参考和待执行动作；`M112OK` |
| `M999` | 已有故障时显式重新检查并真实回零；`M999: homing started`后等待`M999OK` |

M126/M127 使用表中的大写无参形式。视觉工位版另编入 `M413` 关节往返诊断。常规分拣按表中协议执行。不存在G28/G90/G91/G92、任意舵机角度、串口切PS2或独立静音状态查询命令。START/KEEP/WAVE等属于其他专用诊断固件，不能混发。

## 受理和完成

G0/G1至少有XYZF之一；省略轴/速度继承此前已接受参考，建议明确填写全部XYZF。190已同步PS2受理增量到缺省坐标参考，但这不等于测得真实末端位置。不可达/越软限位/非法速度等会拒绝。

发送一个已确认允许的目标，例如格式 `G1 X5 Y190 Z235 F120`；收到`ok`或`queued`后发送`M400`，收到完成`ok`再查`M114`/`M409`。不要把三行同毫秒批量发送，前一条规划待处理时可能回复`previous command pending`。`queued`不保证后续校验成功。

`M400` 在运动后的稳定窗口内继续等待，有待执行补偿或反馈过期时也继续等待。等待期间如果触发安全故障，返回 `error: M400 aborted by safety fault`。夹爪状态单独用 `M410` 查询。

动作要求READY、HOMED:1、ALLOWED:1、MODE:GCODE、FAULT:0、MOTION_FAULT:0。查询可在PS2及故障状态使用；M114需有效参考。无命令编号/去重/校验和，超时不能判定命令未执行，不自动重发运动、夹爪或M999。

## 反馈与视觉接口

`M114 PLAN`是规划参考；`J`/`M409 JOINT`为关节角，`ENC`/`M409 MOTOR`为电机轴角。各掩码bit0/1/2对应M1/M2/M3，正常有效且新鲜通常为7；只有FRAME:JOINT且参考有效时能用关节参考。夹爪没有机械位置传感器。

[配套上位机](https://github.com/zhecd/robotarm-color-sorting-host) 负责相机预览和标定，按末端相机外参将识别目标换算为模型坐标。上位机通过 `G1`、`M400`、`M409` 控制并核对运动，回到拍照位后检查桌面特征偏移。固件负责串口、运动和编码器反馈，图像校验在上位机执行。

## 故障恢复

M112经串口/主循环处理，不是硬件断电；停止后M3可能重力回移。M999仅在已有故障且不在检查/回零时受理，重新建立参考；不能在无故障READY时当普通回零按钮。回零220秒截止，通信应覆盖检查开销（参考客户端240秒）。失败不自动重试。

TMC静音配置成功启动日志分别输出`# TMC_QUIET NODE:0/1/2 CONFIGURED:1 ...`，由IFCNT增量和可读配置读回确认。它不等于实际DRV_STATUS.bit30已观测，也不证明机械噪声消失。
